# C-Clean · Windows C 盘可视化清理工具

一个帮你**看清 C 盘空间构成、找出大头、并安全清理**的桌面工具。

核心理念:先让你明白"C 盘到底为什么这么大、哪些东西占了多少",再由你自己决定怎么删——而不是替你做主、挨个文件去翻。

---

## 技术栈

- **C# + WPF(.NET 8,`net8.0-windows`)**
- 纯原生 Windows,无第三方 UI 框架
- 深色高级仪表盘风格,主色青绿→青蓝渐变 `#2EE6C0 → #17B6E6`

## 如何运行

```powershell
# 在项目根目录
dotnet run
```

需要已安装 .NET 8 SDK。修改代码后 `dotnet run` 会自动重新编译。

## 功能(已完成)

### 📊 空间分析(主视图)
- **彩色方块 treemap**:从 `C:\` 根开始,每个文件夹/文件画成一个方块,**面积 = 占用大小**。一眼看出谁是大头,包括平时看不见的 `hiberfil.sys`、`pagefile.sys` 等系统大文件。
- **下钻 / 返回**:双击文件夹进入下一层,⬆ 返回上级回退;面包屑显示当前路径。
- **单击方格** → 右侧详情面板给出**这是什么 + 清理建议 + 安全等级**,并可"打开目录"或"删除到回收站"。
- 顶部环形仪表盘显示真实的 C 盘已用/总容量。

### 🧹 可清理项
- 按**安全分级**分组列出可清理内容:
  - 🟢 **可安全清理**:缓存/临时/日志,删后自动重建(默认勾选)
  - 🟡 **删除后会丢文件**:回收站、游戏录屏、微信/QQ 接收的文件与图片视频
  - 🔴 **谨慎**:聊天记录、已安装程序——**不参与一键清理**,只能用"打开目录"手动处理
- **真实删除**:勾选后一键清理,**默认删除到回收站(可恢复)**,底部可切换为永久删除。
- 内置扫描器:系统缓存/临时/回收站、NVIDIA 缓存与日志、游戏录屏、微信/QQ 文件、大型已装软件(读注册表体积)。

### 通用
- 深色标题栏(DWM)、异步扫描(不卡界面)、目录大小并行计算 + 缓存。

## 安全设计(重要)

- **默认删除到回收站**,而非彻底删除,留后悔余地。
- **🔴 高风险项**(聊天记录数据库、已装程序)**绝不参与一键删除**,只提供"打开目录"。
- 微信/QQ 只删精确子目录(`File/Image/Video`、`FileRecv` 等),**不碰聊天数据库**。
- 目录大小统计跳过符号链接、逐目录容错,绝不因单点报错而误删。
- 清空回收站走系统接口 `SHEmptyRecycleBin`。

## 可以尝试的操作

1. **找出 AppData 里的空间大户**
   空间分析页 → 双击 `Users` → 双击你的用户名 → 双击 `AppData` → 看哪个软件的数据最占地方,单击它看建议。
2. **看清系统大文件**
   在 `C:\` 根目录层就能看到 `hiberfil.sys`(休眠文件)、`pagefile.sys`(虚拟内存)有多大,单击查看处理建议。
3. **安全地试一次真实清理**
   切到"可清理项" → 只勾选 🟢 **系统与用户临时文件** → 确认底部"删除到回收站"已勾 → 点"立即清理" → 看释放是否正确,需要可从回收站恢复。
4. **手动处理聊天文件**
   "可清理项"里找到微信/QQ 项 → 点"📂 打开" → 在资源管理器里自己挑要删的。
5. **定位某个超大文件**
   空间分析页里双击一个大文件方块 → 自动在资源管理器中选中它,便于直接删除。

## 已知限制

- **首次分析 `C:\` 较慢**(需递归统计 Windows / Users 等大目录),进过的目录会缓存,再进很快。
- **非管理员运行**时,部分系统目录"拒绝访问",统计大小会偏小(treemap 里显得比实际小)。
- 微信/QQ 的"聊天记录及其它数据"是**估算值**(账号目录总量减去已识别的缓存/文件)。
- "大型已装软件"的时间是**安装日期**,不是最后使用时间(Windows 无可靠的最后使用记录)。
